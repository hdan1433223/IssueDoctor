# 标注指南

- Issue 类型：只允许 `Bug`、`Feature`、`Question`、`Docs`、`Other`。
- Bug 完整性：复现步骤、期望行为、实际行为、环境信息均可从正文直接找到时标为 `complete`，否则为 `incomplete`。
- 重复候选：两条 Issue 描述的是同一根因或同一用户可见问题时标为 `duplicate`，仅主题相近标为 `distinct`。
- 关闭原因：Issue 正文、关闭评论或关联 PR 给出可理解原因时标为 `clear`，否则为 `unclear`。
- AI 证据一致性：解释中的每个事实都能在快照证据中定位时标为 `consistent`，否则为 `inconsistent`。

标注者必须记录对象 URL 或快照编号，不得仅凭标题判断。对不确定样本应先标记在 notes 中，并在纳入正式指标前完成复核。
