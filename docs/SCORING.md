# 六维评分说明

评分配置位于 `config/scoring.default.yml`，当前版本为 `1.0`。每个指标只使用快照中的可验证
字段，通过阈值插值转换为 0–100 分。没有足够数据的指标标记为 N/A；其权重按剩余适用指标
动态归一化，而不是强行记 0 分。

| 维度 | 关注点 |
| --- | --- |
| D1 响应效率 | 首次维护者响应、中位响应时间、未响应比例 |
| D2 处理与积压 | 关闭速度、长期积压、陈旧开放 Issue |
| D3 信息质量 | Bug 复现、期望/实际、环境和低信息正文 |
| D4 分类与标签 | 标签覆盖、类型标签、标签数量与一致性 |
| D5 协作闭环 | Issue→PR、PR 合并、关闭原因、参与度 |
| D6 重复与知识 | 相似候选、重复关闭、治理文件基础设施 |

总分是维度有效权重的加权平均。置信度反映数据完整性、样本量和截断状态；没有 LLM Key 不会
降低数据置信度。LLM 不参与任何健康分计算。具体阈值、方向和名义权重以版本化 YAML 为准。
